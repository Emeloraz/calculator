Calculator Web App

A simple, responsive calculator web app built with vanilla 
HTML, CSS, and JavaScript. Users sign in through a login page
and are then taken to a fully working calculator.

Features
User login page: a sign-up/login form that validates input before 
giving access to the calculator
Working calculator: addition, subtraction, multiplication, and division
Clear and delete: reset the whole calculation or remove the last entry
Clean, responsive layout styled with custom CSS

Tech Stack
Technology:	   Purpose:
HTML5	         Page structure (login page and calculator)
CSS            Layout and styling
JavaScript	   Calculator logic and form handling
